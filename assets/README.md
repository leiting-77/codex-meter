# Codex Meter icon

Original project icon generated using the built-in imagegen tool. Included under
the project's MIT license. This is a community app mark, not an OpenAI logo.

- `codex-meter.png`: selected app icon: milky frosted shell, lavender card and two yellow quota bars.
- `icon-quota-prompt.txt`: exact built-in generation prompt for the selected icon and its accepted material reference.
- `codex-meter.ico`: 16, 20, 24, 32, 40, 48, 64, 128, 256 px Windows icon.
- Regenerate the ICO on Windows with `scripts/build-icon.ps1`. This conversion
  is optional; normal builds embed the checked-in ICO without additional runtime dependencies.

Design summary: A rounded milky-glass tile with a pale-lavender frosted card and
two ivory/yellow quota progress bars. This design was selected by the user to
match the software UI. Transparent outer margins; no text, numerals or wordmark.
The full generation prompt is saved in `icon-quota-prompt.txt`.
Local design explorations and screenshot references are excluded from the public source repository.

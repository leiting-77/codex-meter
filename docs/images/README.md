# 演示截图

这些图片来自 Codex Meter v0.3.1 的实际 Windows 演示窗口，未经界面重绘。截图仅包含应用窗口区域，使用虚构账号与额度，不读取真实登录信息。

| 图片 | 展示内容 |
| --- | --- |
| compact.jpg | 紧凑模式，多账号短周期及周额度 |
| details.jpg | 展开详情，重置时间、重置卡明细和移除按钮 |
| edge-dock.jpg | 贴顶横向收纳，默认文字头像和双额度圆环 |

## 复现

```powershell
.\codex_meter.exe --demo --windowed --data-dir "$env:TEMP\CodexMeter-DocsDemo"
```

1. 启动后为紧凑模式；绿色按钮展开详情，黄色按钮收起。
2. 拖动顶栏至屏幕边缘进入收纳模式，或从右键菜单选择“边缘收纳模式”。
3. 单击圆环条恢复；按住拖动可沿当前边缘移动。

演示数据的重置时间相对启动时刻生成，因此重拍时日期与倒计时会不同。截图中的重置卡属于演示数据，实际账号只展示官方服务返回的信息。磨砂效果、字体与窗口尺寸可能随 Windows 版本、背景、显示缩放及设置而不同。
